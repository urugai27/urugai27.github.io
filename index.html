Firebaseは、Googleが提供するクラウドベースのアプリ開発プ
ラットフォームです。

お勉強のため、無料のファイアベースを利用して『ギーマの話
』（２０２１年９月から）というウェブサイトを作っているの
ですが、おととい（２０２６年９月２７日）から、
Error: An unexpected error has occurred.
とエラー（予期せぬ障害）になりました。環境を最新にしても
ダメでした。ところが、ファイアベースからメールが来ました
。お！、障害の件か

違いました、

２０２６年１０月１５日より、新規作成されるプロジェクトに
おいて、Ｆｉｒｅｂａｓｅ　Ｈｏｓｔｉｎｇは、「オンデマン
ドでのサイトプロビジョニング」方式に移行します。

何やら、手順が変わるらしい。ま、『ギーマの話』は２０２６
年８月１１日からヤフー検索の一覧で出なくなったしと諦めて
いたが、ダメもとで環境を最新したら、動きました。

npm install -g firebase-tools　　のコマンドを実行した

ついでに、バタフライピーの記述の訂正があったので直しまし
た。

なお、『ギーマの話』のリンクは、やめました。そのうちリン
ク先を変える予定です。
